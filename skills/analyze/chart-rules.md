# Chart rules

Choose the smallest visualization that answers the question.

| Analytical shape | Chart type |
|---|---|
| Metric over ordered time | line |
| Categories compared by value | bar |
| Pipeline stages | funnel |
| Contributions to a diagnosis | contribution-bar |
| One headline value | metric |
| Exact values or unsupported shape | table |

Do not use pie charts. Use no more than three visualizations in one output. Every field referenced by a visualization must exist in its evidence data.
